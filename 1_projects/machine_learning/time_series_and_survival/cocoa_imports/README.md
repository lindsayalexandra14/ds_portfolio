# forecasting

**Author:** Lindsay McFarlane

## Purpose
Forecast the next quarter of US Cocoa Bean imports to estimate revenue. Used various models to find the best one (Smoothing, SARIMA, Prophet) and tested impact of log transformation on results.

## Contents
- Library requirements (used) 
- CSV ("us_cocoa_imports") provided, but used API call in notebook  
- IPython notebook (on Python 3 kernel, includes Google Colab link)

## Tech Setup
- Python in Google Colab (3.12.12)
